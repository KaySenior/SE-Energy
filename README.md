# SE Energy

## Run locally

### 1. Install dependencies

```bash
make setup
```

### 2. Start the API

```bash
make api
```

The API runs at `http://localhost:8000`.

### 3. Start the app

In another terminal:

```bash
make web
```

The app opens at `http://localhost:5173`.

## Other platforms

```bash
make ios
make android
make macos
```

## Run with Docker

```bash
make docker
```
